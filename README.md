# نظام فرناس المتكامل

تطبيق ويب عربي (RTL) لإدارة عقود وأسطول تأجير السيارات — شركة فرناس المستقبل المحدودة.

## التشغيل محلياً

```bash
npm install
npx prisma migrate dev   # ينشئ قاعدة بيانات SQLite محلية (prisma/dev.db)
npm run db:seed          # يستورد بيانات العقود والعملاء والسيارات... من ملف الإكسل الأصلي
npm run dev
```

افتح http://localhost:3000 وسجّل الدخول بأحد الحسابات التجريبية:

| الدور    | البريد                  | كلمة المرور |
| -------- | ------------------------ | ----------- |
| مدير     | admin@farnas.sa          | admin@2026  |
| محاسب    | accountant@farnas.sa     | acc@2026    |
| مشرف     | supervisor@farnas.sa     | sup@2026    |

## البنية

- **Next.js (App Router) + TypeScript + Tailwind CSS** — واجهة عربية RTL بألوان هوية فرناس.
- **Prisma + SQLite** — قاعدة بيانات مشتركة يراها كل المستخدمين وتحفظ كل تعديل. يمكن استبدال SQLite بـ PostgreSQL لاحقاً بتغيير `DATABASE_URL` فقط.
- **`src/lib/calc.ts`** — محرك الحسابات الذي يطابق معادلات ملف الإكسل الأصلي (الاستحقاق، السداد، التأخير، الأولوية، قائمة الدخل...).
- **الصلاحيات**: مدير (كل شيء) · محاسب (السندات، الرواتب، المصروفات، الالتزامات، المستندات) · مشرف (قائمة المتابعة وطلبات الإفادة فقط، بدون أرقام الربح).
- **الطباعة**: كل مستند (سند قبض، مطالبة، طلب إفادة، عقد، عرض سعر) له صفحة طباعة مخصّصة بشعار الشركة، يمكن حفظها PDF مباشرة من نافذة الطباعة في المتصفح.
